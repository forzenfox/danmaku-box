## 1. 测试范围与目标

### 1.1 测试对象

构建产物 `danmaku-box/dist/`（13 个文件），加载于 Chrome 与 Edge（Chromium 内核）最新两个大版本。

### 1.2 测试目标

| # | 目标 | 对应验收 |
|---|------|---------|
| T1 | P0-P6 全部功能在真实浏览器环境回归通过 | FR-01 ~ FR-06 交互验收 |
| T2 | G1-G5 目标按原型走查口径达标 | 原型设计第 4 章 |
| T3 | 性能指标满足 PRD 第 7 章 | 面板打开 ≤500ms、千条搜索 ≤300ms、右键菜单 ≤100ms、回填 ≤200ms |
| T4 | Chrome / Edge 双内核行为一致 | PRD 第 7 章兼容性 |
| T5 | 隐私与数据安全符合承诺 | 零上传零埋点、破坏性操作可挽回 |
| T6 | 登录态复测裁决开放问题 Q1/Q5 | PRD 第 8 章 |

### 1.3 测试边界

- 本次为**手工功能验收与性能实测**，自动化单元/契约测试（123 例）已由 P0-P6 交付，不在本文档重复。

## 2. 测试环境与前置

| 项 | 要求 |
|----|------|
| 浏览器 A | Chrome 最新稳定版（≥114，需支持 sidePanel API） |
| 浏览器 B | Edge 最新稳定版（Chromium 内核 ≥114） |
| 扩展加载 | `chrome://extensions` / `edge://extensions` → 开发人员模式 → 加载已解压的扩展程序 → 选择 `dist/` |
| 测试直播间 | 斗鱼任意在线直播间（建议选择弹幕密度高的房间，如 `douyu.com/1126960`） |
| 登录态 | 分「未登录」与「真实登录」两轮执行（登录态仅用于 Q1/Q5 复测，见第 10 章） |
| 测试数据 | 构造千条级弹幕库（见第 3 章） |
| 工具 | 浏览器 DevTools Performance 面板、`performance.now()` 打点、Network 面板 |

**前置检查（每个用例执行前）**：确认扩展已加载且图标出现、进入测试直播间后图标点亮（未点亮则先查冒烟检测，见 TC-SITE-01）。

## 5. 目标验收映射（G1-G5）

操作计数口径（原型 V0.2 第 4 章）：一次鼠标点击（含左键/右键）计 1 步；键盘输入、悬停不计；图标点击打开面板计 1 步。

| 编号 | 目标 | 走查步骤 | 预期 | 优先级 |
|------|------|---------|------|--------|
| TC-G1-01 | G1：看到弹幕→完成收藏 ≤2 步 | ① 右键弹幕（1 步）→ ② 点击「默认收藏」末项（1 步）→ toast | 2 步 ≤2 达标 | P0 |
| TC-G1-02 | G1：最近使用分组场景 | ① 右键弹幕 → ② 点击排前分组 | 2 步达标（无需滚动） | P1 |
| TC-G2-01 | G2：打开库→弹幕入框 ≤3 步 | ① 点图标开面板（恢复上次分组，1 步）→ ② 点击目标分组（1 步）→ ③ 点击条目回填（1 步） | 最坏 3 步 ≤3 达标 | P0 |
| TC-G2-02 | G2：恢复分组即目标分组 | ① 开面板 → ② 点击条目回填 | 2 步达标 | P1 |
| TC-G3-01 | G3：数据 100% 本地 | 断网状态下完成收藏/管理/回填全链路 | 全功能可用，无任何外部请求 | P0 |
| TC-G3-02 | G3：无埋点 | Network 面板全程观察扩展请求 | 除斗鱼页面自身资源外，扩展不发起任何网络请求 | P0 |
| TC-G4-01 | G4：一期核心功能离线可用 | 断网后收藏→浏览/搜索→回填→导出/导入 | 全链路可用，不依赖外部服务 | P0 |
| TC-G5-01 | G5：二期不改通用层（架构核对） | 技术评审核对：适配器接口与通用层解耦 | 新增抖音适配器不改动弹幕库/分组/备份逻辑 | P1（评审项） |

## 10. 登录态复测用例（Q1 / Q5，需真实登录会话）

> 前置：真实登录的斗鱼/抖音账号，浏览器保持登录态。此轮复测为发版前置验收项（技术方案 P7），复测方法与 2026-08 实地验证一致。

### 10.1 Q1 斗鱼原生右键面板共存

| 编号 | 前置 | 步骤 | 预期 | 优先级 |
|------|------|------|------|--------|
| TC-Q1-01 | 斗鱼登录态 | 在弹幕上右键，观察原生右键面板是否出现 | 记录实测：登录态是否触发原生面板（未登录实测不触发，需确认） | P0 |
| TC-Q1-02 | 原生面板出现时 | 插件自定义菜单与原生面板同时出现 | 两者偏移展示、互不遮挡（技术方案 Q1 承接方案：菜单偏移可配置） | P0 |
| TC-Q1-03 | 同左 | 分别操作原生面板与插件菜单 | 互不干扰，收藏能力均可用 | P1 |
| TC-Q1-04 | 同左 | 设置中关闭「聊天区右键收藏」 | 插件菜单不出现，原生面板完全可用 | P1 |

**裁决**：依据 TC-Q1-01~04 结果，评审 Q1 共存形态（偏移并排 / 原生面板内注入入口 / 替换），定版菜单实现。

### 10.2 Q5 抖音飘屏路径（二期）

| 编号 | 前置 | 步骤 | 预期 | 优先级 |
|------|------|------|------|--------|
| TC-Q5-01 | 抖音登录态进入直播间 | 观察弹幕列表 DOM 是否渲染 | 记录实测：登录态下弹幕列表渲染、输入框出现（未登录实测不渲染） | P0 |
| TC-Q5-02 | 同左 | DevTools 探测飘屏弹幕实现方式 | 记录实测：飘屏为 DOM 节点还是 Canvas，决定飘屏收藏路径是否纳入二期 | P0 |
| TC-Q5-03 | 同左 | 右键弹幕列表条目 | 记录可收藏性（二期适配器验证点） | P1 |

**裁决**：依据 TC-Q5-01~03 结果，评审 Q5 抖音飘屏路径是否纳入二期范围。
