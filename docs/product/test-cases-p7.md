## 1. 测试范围与目标

### 1.1 测试对象

构建产物 `danmaku-box/dist/`（13 个文件），加载于 Chrome 与 Edge（Chromium 内核）最新两个大版本。

### 1.2 测试目标

| # | 目标 | 对应验收 |
|---|------|---------|
| T1 | P0-P6 全部功能在真实浏览器环境回归通过 | FR-01 ~ FR-07 交互验收 |
| T2 | G1-G5 目标按原型走查口径达标 | 原型设计第 4 章 |
| T3 | 性能指标满足 PRD 第 7 章 | 面板打开 ≤500ms、千条搜索 ≤300ms、右键菜单 ≤100ms、回填 ≤200ms |
| T4 | Chrome / Edge 双内核行为一致 | PRD 第 7 章兼容性 |
| T5 | 隐私与数据安全符合承诺 | 零上传零埋点、破坏性操作可挽回 |
| T6 | 登录态复测裁决开放问题 Q1/Q5 | PRD 第 8 章 |

### 1.3 测试边界

- 本次为**手工功能验收与性能实测**，自动化单元/契约测试已由 P0-P6 交付（含本次去重用例，数量以实际测试报告为准），不在本文档重复。
- 仅覆盖一期斗鱼；抖音（二期）不在本期范围。
- 不做自动化发送、不触碰账号凭据（遵守「只回填不代发」原则）。

## 2. 测试环境与前置

| 项 | 要求 |
|----|------|
| 浏览器 A | Chrome 最新稳定版（≥114，需支持 sidePanel API） |
| 浏览器 B | Edge 最新稳定版（Chromium 内核 ≥114） |
| 扩展加载 | `chrome://extensions` / `edge://extensions` → 开发人员模式 → 加载已解压的扩展程序 → 选择 `dist/` |
| 测试直播间 | 斗鱼任意在线直播间（建议选择弹幕密度高的房间，如 `douyu.com/1126960`） |
| 登录态 | 分「未登录」与「真实登录」两轮执行（登录态仅用于 Q1/Q5 复测，见第 10 章） |
| 测试数据 | 构造千条级弹幕库（见第 3 章） |
| 工具 | 浏览器 DevTools Performance 面板、`performance.now()` 打点、Network 面板 |

**前置检查（每个用例执行前）**：确认扩展已加载且图标出现、进入测试直播间后图标点亮（未点亮则先查冒烟检测，见 TC-SITE-01）。

## 3. 测试数据构造方法

| 数据 | 构造方式 | 用途 |
|------|---------|------|
| 千条级弹幕库 | 通过弹幕库面板「手动新建」批量录入，或导入预生成的千条 JSON 备份（`danmaku-box-备份-*.json`） | 性能用例（搜索/滚动/打开） |
| 50 字边界 | 构造 49/50/51 字内容 | 字数上限与截断用例 |
| 空文本弹幕 | 纯表情无文字弹幕（右键收藏后 content 为空） | 空文本置灰用例 |
| 富内容弹幕 | 含表情/图片的弹幕 | 富内容提取用例 |
| 超长弹幕 | 100+ 字内容（手动新建时输入框限制 50，需通过导入构造） | 回填截断用例 |
| 同名分组备份 | 构造与当前库同名的分组名 | 导入合并用例 |
| 跨组导入备份 | 当前库 A 组有内容 X，备份文件 B 组有相同内容 X | 合并导入全库去重用例 |
| 备份内部跨组重复 | 同一备份文件 A、B 组各放 1 条相同内容 | 备份内部去重用例 |
| 组内重复数据 | 同一分组内构造 2-3 条相同内容（含首尾空格变体） | 组内去重用例 |
| 默认收藏跨组重复 | 默认收藏与自定义 A 组各放 1 条相同内容 | 跨组去重（删除默认收藏）用例 |
| 非默认跨组重复 | 自定义 A、B 两组各放 1 条相同内容 | 跨组去重（保留）用例 |
| 空文本重复 | 通过导入构造同一分组内 2 条空文本条目 | 空文本跳过用例 |
| 官方收藏重复 | 登录态下拉取官方收藏；构造官方列表内部重复（跨库重复由自动化契约测试覆盖） | FR-07 批次内去重用例 |
| 混合重复库 | 同时包含：同组重复、默认收藏+自定义跨组重复、非默认多组重复、无重复条目 | 去重专项集成用例 |
| 归一化变体 | 同内容构造首尾空格变体（`" X "` / `"X"`）、大小写变体（`ABC` / `abc`）、全角变体（`Ａ` / `A`） | 去重归一化边界用例 |
| 同内容不同来源 | 通过导入构造内容相同但 platform/room/created_at 不同的条目 | 去重判定维度用例 |
| 重复导入同一备份 | 保留同一份备份文件，连续执行两次「合并导入」 | 导入幂等用例 |
| 旧版本备份 | 修改备份文件 `version` 为非 1 值 | 版本迁移用例 |
