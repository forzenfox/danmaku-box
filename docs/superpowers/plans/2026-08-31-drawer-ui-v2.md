## Task 2：新增公开方法 hide()（drawer-host.ts，TDD）

**a. 契约测试先行（红灯）** —— 补充用例：

```ts
test('hide() 收起并写回会话关闭态', async () => {
  const { doc } = makeFakeDoc();
  let saved: Record<string, unknown> | null = null;
  const session = {
    get: async () => undefined,
    set: async (items: Record<string, unknown>) => { saved = items; },
  };
  const host = createDrawerHost({ doc, getURL: () => '', session });
  host.mount();
  host.toggle();            // 开
  assert.equal(host.isOpen(), true);
  host.hide();              // 程序化收起
  assert.equal(host.isOpen(), false);
  await Promise.resolve();  // 等 persist 微任务
  assert.equal((saved as any)['drawer.ui'].open, false);
});
```

- 接口扩展：`DrawerHost` 增加 `hide(): void`；未挂载/已关闭时调用幂等不报错（补一个幂等断言可选）。

**b. 实现** —— drawer-host.ts：

```ts
function hide(): void {
  applyOpen(false); // 不动 lastOpen（用户显式意图保留，供全屏退出恢复）
  persist();        // 会话记忆写回关闭态
}
```

**c. 门禁**：`npm run test` → `npm run check`。

- [ ] commit: `feat(drawer): DrawerHost 新增 hide() 程序化收起（applyOpen(false) + persist）`

## 风险与注意

- **常量漂移**：62vh/560px/40vw 参数集中在 DRAWER_STYLES 并以单测断言钉住（Task 1），后续改动需先改测试。
- **死代码**：行内删除确认态分支随入口移除必须同步删除（Task 3），防止 lint 门禁失败或隐藏分支。
- **时序**：Task 4 的 900ms 延迟为 spec 既定值，不在代码里另加可配置项（YAGNI，spec §8）。
- **不做**：F11 事件监听、抽屉内嵌输入框/发送、主题切换、动画定制（spec §8）。
